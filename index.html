Projects

Here are some of the projects I've worked on. More coming soon!

HQ-CML — Exploring a Hybrid Quantum–Classical ML Framework for Financial Fraud Detection Graduation Project

Compares Classical ML, VQC, QNN, QSVC, and Hybrid RF+QSVC & XGB+QSVC stacking ensembles for financial fraud detection — 150+ logged experiments across 5 model families on the PaySim dataset (6.3M rows, 0.13% fraud rate). The Hybrid 6-qubit model achieved 100% F1 & Recall. Includes an interactive Streamlit dashboard.

Python Qiskit Quantum ML XGBoost Scikit-learn Streamlit

Balaagh AI — بلاغ (SIC AI Capstone)

End-to-end Arabic NLP platform for classifying and prioritizing crisis reports. AraBERT reached 91.3% macro F1 on 6 incident categories; MARBERT handles location NER. Built on 1,180 Arabic samples — React + Vite + Leaflet map + TanStack Query frontend, FastAPI + PostgreSQL (Supabase) backend, Docker, CI/CD via GitHub Actions, and 51 passing tests.

Python AraBERT MARBERT FastAPI React PostgreSQL Docker GitHub Actions

EE569 CarRacing Challenge — Deep RL

EE569 assignment: trained a Double DQN agent on Gymnasium's CarRacing-v3. Achieved a best score of 915.75 (target: 700) over 627K training steps using 4-frame stacking, experience replay (50K buffer), target network updates, and Aim experiment tracking — trained on a local MX450 GPU.

Python PyTorch Deep RL Double DQN Gymnasium

IHMS — Intelligent Healthcare Management System

Intelligent Healthcare Management System for Libyan medical institutions. Clean Architecture with 6 layers, 21 entity models, and portals for Admin, Doctor, and Patient roles. Features appointment scheduling, real-time telemedicine chat, medical records, Arabic/English UI, MSTest unit tests with Moq, and Libyan data localization.

ASP.NET Core 8 C# SQL Server EF Core Bootstrap 5 MSTest + Moq
